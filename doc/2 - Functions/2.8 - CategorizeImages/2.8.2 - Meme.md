# 2.8.2 Category: Meme (v0.3)

- Internal name: `Meme`
- GUI label: **Memes**
- Target folder: `ToDelete/Memes`, next to `ToDelete/Doublets` (`target` `ToDelete`, Razen, 2026-10-30)
- Definition file: `System/Config/Categories/Meme.json`
- Part of `2.8 - CategorizeImages.md`. Common rules (procedure, preview, log, undo, Default) are defined there.
- Language: this document and the definition file are in English. Only GUI-visible values are in German.

## 1. Purpose
- Memes are sorted out, to be deleted later (Razen, 2026-10-30). Like the duplicates, they go into `ToDelete`, which you empty yourself. The tool never deletes them (base rule).
- Files keep their name (`rename` `false`), no keyword needed, since they will be deleted anyway.

## 2. What belongs here
- Funny pictures with sayings or captions, image macros, joke pictures, reaction images, funny comics and screenshots of jokes shared in chats or social media.

## 3. What does not belong here
- Own photos of people, places or events, even if they are funny. Default (or the event workflow).
- Screenshots with useful content (recipes, documents, information). Their own category or Default.
- When in doubt, not a meme: an image wrongly sorted out would be deleted later, so Claude must be sure (higher confidence limit, section 5).

## 4. Definition file (sent to Claude word for word)
```json
{
  "name": "Meme",
  "label": "Memes",
  "folder": "Memes",
  "target": "ToDelete",
  "rename": false,
  "minConfidence": 0.85,
  "namePatterns": ["meme", "9gag", "funny", "lustig", "witz", "lol", "haha", "spruch", "sprueche", "reddit", "imgflip", "giphy"],
  "definition": "The image is a meme: a funny picture with a saying or caption, an image macro, a joke picture, a reaction image, a funny comic or a screenshot of a joke as shared in chats or social media. Personal photos of people, places or events are NOT memes, even if funny. Screenshots with useful information (recipes, documents, instructions) are NOT memes. If unsure, it is NOT a meme."
}
```

## 5. Safety
- Because Memes are meant to be deleted, a higher limit applies: `minConfidence` `0.85` in the definition file (overrides `minCategoryConfidence` of 2.8 for this category, proposal). Below it the row is unchecked.

## 6. Pre-assessment by file name
- `namePatterns` (see 2.8 section 5a): words typical for meme downloads, e.g. `9gag_…`, `meme_…`, `imgflip_…`. List in section 4.
- WhatsApp names (`IMG-20230101-WA0001`) are not a meme pattern: they also come with normal photos.
- A file is never moved to `ToDelete/Memes` checked on the file name alone (2.8 section 5a).

## 7. Open questions
- None. Folder decided: `ToDelete/Memes` (Razen, 2026-10-30). Like all of `ToDelete`, it is hidden in the explorer (base v0.24).
